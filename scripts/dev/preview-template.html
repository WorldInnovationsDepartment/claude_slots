Claude Slots Preview

A browser-side preview of the Claude Slots plugin's slot machine, rendered with the exact same lib/ engine (state machine, art builders, RNG, economy) that drives the real Claude Code spinner replacement — bundled here into one inline script with no server and no network requests, purely for visually reviewing frames, timing, and every outcome without a live Claude Code session.

claude --plugin-dir /path/to/claude_slot — run Claude Code with this plugin loaded
